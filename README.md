The Function:

The Group consists of Scouts, each scout is a User with a unique id, and has a name, gender, birthday, address, and date of becoming part of the Group.
Each Scout member is part of only one Scout subgroup, belongs to only one unit in that subgroup and that member has a level in that subgroup.
Each Scout Subgroup has a unique id, a unique name, a patron saint, and only one leader.
Each Subgroup has its own units, each unit has a unit leader and a unit leader assistant, a unique name, and only people of the same subgroup can be in it.
Each level in the subgroup has its own tasks, that can be modified only by the leader of that subgroup.
Each task has a unique ID, a task name, a task description, a number of points ascribed to it, and when a task is completed by a scout, the date of completion is assigned. 
The leader is a scout, and may have one or more assistant leaders.
each leader has atleast one title (subgroup_leader, group_leader, subgroup_leader_assistant, group_leader_assistant, 'logistics_coordinator', 'program_manager', 'general_secretary', 'financial_officer', 'media_officer'), a date in which they became a leader.
